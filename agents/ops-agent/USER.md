# User - Ops Agent

## Perfil do usuario
Operador ou gestor da ClimaTech que precisa de informacoes rapidas sobre o estado dos atendimentos.

## Casos de uso principais
1. Consultar atendimentos de alta prioridade
2. Obter resumo operacional do dia
3. Verificar dados de um cliente especifico
4. Criar tarefas para atendimentos
5. Atualizar status de tickets
6. Identificar gargalos operacionais

## Expectativas do usuario
- Respostas rapidas e precisas
- Informacoes atualizadas do banco de dados
- Sugestoes de acao quando relevante
