# Skill: Gestao de Tarefas

## Descricao
Cria e gerencia tarefas associadas a atendimentos.

## Quando aplicar
Quando um atendimento requer uma acao concreta por parte da equipe tecnica.

## Tipos de tarefas comuns
- Visita tecnica para diagnostico
- Orcamento presencial
- Instalacao agendada
- Manutencao preventiva
- Retorno de garantia

## Fluxo recomendado
1. Identificar o ticket relacionado
2. Definir titulo claro e objetivo
3. Adicionar descricao com contexto relevante
4. Criar a tarefa via ferramenta create_task
5. Confirmar criacao ao usuario

## Boas praticas
- Titulos devem ser acionaveis: "Enviar tecnico para diagnostico" em vez de "Problema no ar"
- Incluir dados do cliente na descricao para facilitar o atendimento
- Para prioridade CRITICAL, mencionar urgencia explicitamente no titulo
