# Skill: Gestao de Clientes

## Descricao
Consulta e gerencia informacoes de clientes da ClimaTech.

## Quando aplicar
Quando o usuario perguntar sobre um cliente especifico ou precisar de historico.

## Fluxo recomendado
1. Buscar cliente por ID ou nome
2. Apresentar dados principais: nome, empresa, telefone, email
3. Mostrar historico resumido de atendimentos
4. Identificar padroes (cliente recorrente, problemas frequentes)

## Informacoes relevantes a destacar
- Numero de atendimentos anteriores
- Ultimo atendimento e seu status
- Presenca de atendimentos criticos no historico
